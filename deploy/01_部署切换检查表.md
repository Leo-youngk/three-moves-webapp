# 01 部署切换检查表

这份检查表用于将当前已验证版本从海外部署环境切换到中国可用环境。中国版先按 EdgeOne Pages 处理，海外版 Vercel 只作为回退和参考。

## 切换前确认
- [ ] 当前迁移目录独立存在
- [ ] 产品层已经冻结
- [ ] 已明确目标部署平台
- [ ] 已明确目标域名
- [ ] 已明确是否保留海外备用站点
- [ ] 已明确是否需要备案
- [ ] 已明确通知链路是否要同步替换

## 部署准备
- [ ] 配置新的生产环境变量
- [ ] 准备新的静态资源访问路径
- [ ] 准备新的生产域名或子域名
- [ ] 核对 manifest / icon / sw 资源路径
- [ ] 核对 `service worker` 与主站点同源
- [ ] 核对主屏幕启动路径
- [ ] 核对 `edgeone.json` 与 `package.json` 的 Node / build 配置

## 首轮上线后检查
- [ ] 首页可访问
- [ ] Today 可保存并刷新不丢
- [ ] Reminder 可打开
- [ ] Night 可更新状态
- [ ] History 可回看
- [ ] Install 页面可读
- [ ] PWA 安装后图标和名称正确
- [ ] 主屏幕启动正常
- [ ] 中国网络环境下资源可加载

## 切换后回滚条件
- [ ] 首页不可用
- [ ] 安装壳异常
- [ ] 关键资源 404
- [ ] 通知链路不可用
- [ ] 中国网络下主链路不稳定

## 备注
这份检查表当前只做准备，不表示已经开始实际切换。

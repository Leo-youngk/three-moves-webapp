# 03 中国部署配置清单

这份清单只记录中国版部署需要显式管理的内容，不包含产品页面定义。

## 目标平台
- EdgeOne Pages
- 同一套 Next.js 应用
- 共享产品基线，替换基础设施层
- CloudBase Node SDK 直连存储
- SCF Timer Trigger

## 需要显式配置的项目
- `edgeone.json`
- `package.json` 中的 build 命令
- `package.json` 中的 Node 版本约束
- `.nvmrc`
- 生产域名
- DNS 记录
- 生产环境变量
- 静态资源访问路径
- CloudBase 环境 ID
- CloudBase 访问凭证
- SCF Timer Trigger 调用密钥

## 发布前核对
- 构建命令与平台期望一致
- 输出目录为 `.next`
- Node 版本与平台可用版本一致
- `service worker` 资源路径同源
- `manifest` 与图标资源可直接访问
- 主页与 `/install` 入口可打开

## 参考但不作为中国目标的配置
- `vercel.json`
- 海外部署链接
- 海外提醒发送基础设施

## 对应契约
- `infra/05_CloudBase_提醒存储契约.md`
- `infra/06_SCF_Timer_调度契约.md`

## 备注
中国部署配置只能记录平台差异，不记录产品差异。

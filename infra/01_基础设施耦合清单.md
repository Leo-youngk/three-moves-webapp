# 01 基础设施耦合清单

这一份清单专门记录当前中国版候选里，和部署平台、推送链路、调度、静态壳强相关的文件。

## 明显绑定 EdgeOne / 中国基础设施的部分
- `vercel.json`
  - 仍保留海外基线配置，当前中国版不再依赖它做调度
- `package.json`
  - 依赖里仍保留海外基线能力，但中国版提醒存储不再走 Vercel KV
- `src/app/api/reminders/send/route.ts`
  - 使用 Vercel 运行时中的环境变量、Node runtime、定时发送链路
- `src/app/api/reminders/subscription/route.ts`
  - 订阅保存接口，后续可能替换为不同后端
- `src/lib/reminders/server-store.ts`
  - 当前已切到 CloudBase SDK 直连
- `src/lib/reminders/config.ts`
  - VAPID、提醒路径、时区、环境变量读取
- `src/lib/reminders/push-client.ts`
  - push 发送实现，和后端运行环境强相关
- `src/types/web-push.d.ts`
  - 为服务端推送库补类型，属于基础设施支撑代码

## 明显绑定 PWA / 启动壳的部分
- `src/app/layout.tsx`
  - metadata、manifest、Apple Web App 信息
- `public/manifest.webmanifest`
  - 安装名称、图标、启动模式
- `public/sw.js`
  - service worker 与通知点击行为
- `src/components/pwa-registry.tsx`
  - 生产环境 service worker 注册
- `src/app/install/page.tsx`
  - 安装页入口
- `src/components/install-guide.tsx`
  - 安装说明文案
- `public/icons/*`
  - 安装图标与 badge
- `src/app/favicon.ico`
- `src/app/icon.svg`
- `src/app/apple-icon.png`

## 容易出问题的地方
- CloudBase 凭证是否配置完整
- CloudBase 环境 ID 是否一致
- SCF Timer Trigger 的触发时间与鉴权
- VAPID public/private key 是否完整配置
- service worker 是否被旧缓存干扰
- manifest 与 icon 是否和主屏幕启动表现一致
- 订阅保存结构是否和发送结构一致

## 这轮先不要动的部分
- `src/app/page.tsx` 和各页面视觉结构
- `src/components/today-page.tsx`
- `src/components/night-page.tsx`
- `src/components/history-page.tsx`
- `src/components/reminder-page.tsx`
- `src/lib/storage/*`
- `src/lib/domain/*`
- `src/lib/constants/*`

## 迁移原则
- 先把基础设施边界写清楚，再替换实现
- 不要在没有目标平台前提下改接口定义
- 不要把页面层和部署层混写在一起

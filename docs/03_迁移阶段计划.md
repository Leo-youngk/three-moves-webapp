# 03 迁移阶段计划

这是一份迁移路线图，不是实施清单。目标是把当前可用版本复制到中国可用版工作区后，再逐步替换基础设施。

## Phase A：复制版本并冻结产品层
- 从已验证版本复制到独立迁移目录
- 冻结 Today / Reminder / Night / History / Install 的产品定义
- 标记所有不允许在本轮修改的产品层文件
- 建立迁移工作区说明

### 完成标准
- 迁移目录独立存在
- 产品层没有被重写
- 文档明确区分“保留项”和“替换项”

## Phase B：替换部署目标
- 切换到面向中国可用的部署环境
- 替换域名和 DNS
- 核对生产 metadata、PWA 壳、静态资源访问
- 验证首屏和主链路在新环境可用

### 完成标准
- 新环境可访问
- 首页、Reminder、Night、History、Install 都正常
- 主屏幕启动正常

## Phase C：替换提醒基础设施
- 替换通知发送链路
- 替换服务端调度
- 替换 subscription 存储
- 保持通知入口和产品页面不变

### 完成标准
- 用户仍只看到原有产品
- 提醒能力在新基础设施下可用
- 不引入多设备或复杂规则

## Phase D：真机与中国网络验证
- iPhone 真机验证
- 中国网络环境验证
- 域名、证书、资源加载验证
- 提醒链路验证

### 完成标准
- 真机可用
- 中国网络可用
- 没有明显的海外依赖泄漏

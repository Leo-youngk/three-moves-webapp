# 09 中国网络验收清单

这份清单只验证中国网络环境下的可用性，不改产品定义。

## 必须通过的页面
- 首页
- `/install`
- `/night`
- `/history`
- `/reminder/19-00`

## 必须通过的行为
- 刷新后 Today 数据不丢
- 关闭页面后重开 Today 数据不丢
- 夜间状态更新后能回看
- 历史页能按日期显示
- 加入主屏幕后可独立启动
- 主屏幕启动后仍能打开核心页面

## 网络检查方法
- 在中国网络真机上打开，不借助 VPN
- 在运营商网络和 Wi-Fi 下各测一次
- 在应用已安装到主屏幕后再测一次
- 确认首屏资源没有依赖海外域名

## 失败判定
- 任何核心页面只能在 VPN 下打开
- 任一静态资源加载失败导致白屏
- 主屏幕启动后进入的是浏览器壳而不是安装壳
- 提醒页无法在中国网络下打开

# 01 当前版本保留项

本迁移工作区以当前已验证通过的产品版本为基准。下面这些内容在中国可用版迁移前保持原样，不做产品重写。

## 保留的产品层
- Today 页面
- Reminder 页面
- Night 页面
- History 页面
- /install 安装说明页
- 路由结构与页面跳转关系
- 页面文案与信息层级
- 当前已验证通过的交互节奏
- 本地持久化逻辑
- PWA 基础壳能力
- 视觉样式与移动端布局

## 保留原则
- 先保留产品层，不动产品定义
- 先保留页面结构，不改信息架构
- 先保留已验证交互，不引入新功能
- 先保留真机可用性，再替换基础设施

## 说明
如果后续迁移中发现某些基础设施绑定隐藏在产品代码里，应先抽离，不要直接重写页面。

## 冻结检查
- 这份文档代表共享产品基线
- 任何中国版迁移都先对齐这里列出的产品层
- 除非明确进入基础设施替换阶段，否则不要改动这里列出的页面、路由、文案和交互

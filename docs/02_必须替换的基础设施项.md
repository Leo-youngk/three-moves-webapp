# 02 必须替换的基础设施项

这一轮迁移不重做产品，但后续上线中国可用版时，下面这些基础设施必须单独替换或重接。

## 必须替换
- 部署平台
- 域名与 DNS
- 静态资源分发策略
- 通知发送链路
- 服务端定时调度
- 持久化存储
- 生产环境访问策略

## 当前版本中需要关注的基础设施点
- 生产部署仍依赖当前海外部署方案
- PWA 的 manifest、icon、service worker 需要在新基础设施下重新验证
- reminder 链路后续需要能在中国网络环境下稳定送达
- 如果后续引入后端，存储位置和访问路径需要与产品层分离

## 迁移时的关注点
- 站点是否需要国内可访问
- 是否需要备案或替代访问方案
- 通知链路是否依赖海外服务
- 静态资源是否仍然引用海外域名
- 调度任务是否能在目标平台稳定执行

## 当前不动的部分
- 页面本身
- 路由本身
- 视觉本身
- 文案本身
- 本地优先的数据模型

## 冻结说明
这份文档只定义后续中国可用版必须替换的基础设施，不代表现在要改这些实现。当前阶段仍以共享产品基线为准，基础设施替换必须和产品层隔离开。

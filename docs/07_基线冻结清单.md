# 07 基线冻结清单

这份清单的目标很简单：在开始任何中国可用版迁移之前，先确认共享产品基线没有被改坏。

## 冻结对象
- Today
- Reminder
- Night
- History
- /install
- 路由结构
- 页面文案
- 视觉样式
- 移动端布局
- 本地优先的数据模型
- PWA 基础壳

## 允许后续替换的对象
- 部署平台
- 域名
- 静态资源分发
- 通知发送链路
- 服务端定时调度
- 持久化存储
- 环境变量和密钥

## 开始迁移前的检查
- 先核对 `docs/01_当前版本保留项.md`
- 再核对 `docs/02_必须替换的基础设施项.md`
- 再核对 `docs/04_风险与边界.md`
- 再核对 `docs/06_目录地图.md`
- 确认当前迁移只涉及基础设施，不引入产品层变更
- 确认任何新改动都能回退到当前已验证版本

## 完成标准
- 冻结对象没有新增或删除
- 替换对象仍然只限基础设施
- 后续迁移任务可以按这份清单逐项验收
